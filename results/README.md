## 1. Главный результат

Исторический модельный портфель, основная стратегия `DONCHIAN_20D_CLOSE_CONTINUOUS`, моделируемые издержки `cost_mult = 1`.

| Период | Среднегодовая арифметическая net-доходность | Sharpe | CAGR | Максимальная просадка |
|:--|--:|--:|--:|--:|
| 1985–2009 | **+8,94%** | **0,812** | +8,68% | −19,17% |
| 2010–2026 (до июля) | **+0,09%** | **0,008** | −0,58% | −36,86% |
| 2020–2026 (до июля) | **+2,70%** | **0,219** | +1,96% | −27,56% |

Данные: [`summary.csv`](summary.csv). **Среднегодовая арифметическая доходность и CAGR — разные показатели.** Исторические результаты не являются реальными сделками.

## 2. Почему современная доходность исчезла

Для периода с 2010 года, основная модель:

| Условие | Среднегодовая арифметическая доходность |
|:--|--:|
| До модельных расходов (0×) | +3,65% |
| Основные расходы (1×) | **+0,09%** |
| Удвоенные расходы (2×) | **−3,47%** |

Основной причиной ухудшения чистой доходности стала стоимость высокой оборачиваемости (около 153× в год в модели); при `cost_mult = 1` оценённые затраты составляли около 3,56 процентного пункта доходности в год. Ещё до расходов преимущество по современному Sharpe оставалось слабым.

Сравнение по тому же современному периоду:

| Стратегия / тест | Годовая net-доходность | Sharpe |
|:--|--:|--:|
| 20-дневный Donchian, close-proxy | **+0,09%** | 0,008 |
| Контроль Always Long (сопоставимое масштабирование риска) | +9,44% | 0,683 |
| Ранее исследованный TSMOM, 12 мес. | +5,87% | 0,479 |
| Вариант 4 завершённых календарных недель по закрытиям | +0,58% | 0,049 |

Сравнения и определения см. в [`summary.csv`](summary.csv), [`prior_QR2_TSMOM_benchmark.csv`](prior_QR2_TSMOM_benchmark.csv) и [итоговом отчёте](../docs/Quant_Research_6_Donchian_Final_2026-10-14.md). Результаты разных тестов нельзя автоматически считать доказательством превосходства какой-либо стратегии в реальном исполнении.

## 3. Устойчивость результата

Для основной современной модели 12-месячный block bootstrap дал доверительный интервал 95% **от −4,32% до +4,78% годовых**, который включает ноль. Это не подтверждает устойчивое положительное преимущество. Полные оценки см. в [`block_bootstrap.csv`](block_bootstrap.csv).

### Как читать имена и значения

- `DONCHIAN_20D_CLOSE_CONTINUOUS` — основная модель пробоя **по закрытиям** предыдущих 20 торговых дней.
- `DONCHIAN_4_COMPLETED_WEEKS_CLOSE` — отдельная версия на четырёх завершённых календарных неделях, тоже **по закрытиям**.
- `MOP_1985_2009` — исторический период; `POST_2009` — 2010+; `POST_2020` — 2020+.
- `cost_mult` — множитель **модельных** издержек: `0`, `1`, `2` или `3`.
- `ann_arith`, `cagr`, `ann_vol`, `max_drawdown`, `return_net1x` — доли единицы: `0.0894` означает **8,94%**.
- `sharpe` — коэффициент без единиц измерения; `ann_turnover` — годовая оборачиваемость.
- `year_concentration.csv` содержит пустую ячейку там, где показатель неприменим/не определён. Она не должна превращаться в ноль.

Годовой CSV начинается раньше 1985 года, потому что в исходном историческом наборе присутствуют более ранние наблюдения. Основные выводы исследования зафиксированы для указанных выше периодов, а не для всех лет подряд.

## 5. Как нормально открыть таблицы в Excel

**Рекомендуемый способ:** скачайте [`Donchian_Results_Reader.xlsx`](Donchian_Results_Reader.xlsx). В ней уже разделены колонки, настроены проценты, ширина столбцов, фильтры и заморозка заголовков. Девять листов соответствуют девяти CSV, исходные числа не изменены.

Если нужен **именно CSV**, не открывайте его двойным щелчком в русскоязычном Excel. Откройте пустую книгу → **Данные → Из текста/CSV** → выберите файл → установите **Разделитель: запятая** → **Загрузить**. Это решает проблему попадания всего содержимого в столбец A.

**Почему CSV остались с разделителем-запятой:** это стандартный машинный формат для Python и сравнения воспроизводимости. Мы не меняли ни разделители, ни численные значения в архивных CSV ради Excel.
